# Espace d'administration confié à EasyAdmin, hors du thème

L'espace Admin (listes de référence des Instruments et des Towns, Users) sera réalisé avec EasyAdmin, qui fournit sa propre interface : le thème ne contient donc aucune page d'administration. Les étudiants pratiquent déjà le CRUD manuel dans l'espace du Venue Manager (Venues, Gigs, Sessions) ; l'administration devient l'occasion de découvrir un bundle majeur de l'écosystème, et la maquette reste plus légère.
